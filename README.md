# Prompt Studio

Local web app that turns a prompt into a narrated video (storytelling or Shorts) or into images, using only free tools and **no accounts**.

Pipeline: prompt → LLM storyboard (Pollinations text) → images (Pollinations) → narration (edge-tts) → word-timed subtitles → ffmpeg → `mp4`.

## Requirements

- Node.js 24+ and pnpm
- ffmpeg (on `PATH`)
- Python 3 with `edge-tts` ≥ 7.3.1 (`pip install -U edge-tts`)
- Internet access (Pollinations and Microsoft TTS are online services)

Behind a corporate proxy with TLS inspection, the npm scripts already pass `--use-system-ca`.

## Install and run

```
pnpm install
pnpm dev          # http://127.0.0.1:3000
```

Production mode: `pnpm build && pnpm start`.

## Web usage

1. **Home** (`/`): type a prompt, choose duration, language, voice, format (16:9 or 9:16) and style → *Create*. The storyboard is generated by an LLM.
2. **Project editor**: edit narration and image prompt per scene, 🎲 new seed to regenerate one image, pick an image from the library, then *Render*. Progress streams live; only stale scenes are regenerated.
3. **Video panel**: player, download, YouTube metadata (title, description with chapters, tags, `#Shorts`) and *Free disk space*.
4. **Images** (`/images`): generate standalone images, keep them in a library and reuse them in scenes (*Save to library* from any scene).

Data lives in `data/` (git-ignored): `data/projects/<id>` and `data/images`.

## CLI

```
pnpm studio create "<prompt>" [--seconds 60] [--lang en] [--voice <name>] [--no-subs] [--format 16:9|9:16] [--style "..."] [--id x] [--build]
pnpm studio voices [lang|refresh]
pnpm studio new-demo [id] [16:9|9:16]
pnpm studio build <id>      # resumable; generates only stale artifacts
pnpm studio youtube <id>
pnpm studio clean <id>      # deletes per-scene clips
pnpm studio list
```

## Optional configuration

Copy `.env.example` to `.env.local`. `PEXELS_API_KEY` (free key) enables stock photos as an automatic fallback when Pollinations keeps failing. Without it, everything still works.

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| Image step is slow (~45 s per scene) | Pollinations' anonymous limit is 1 image per 45 s per IP (HTTP 402 with Retry-After). The app waits and retries; a 3-scene video takes about 2 minutes. |
| "pollinations.ai" watermark at the bottom right of 16:9 images | Added by the free anonymous tier. Currently accepted (pending decision); use library images or the Pexels fallback to avoid it. |
| Network errors / `unable to get local issuer certificate` | Corporate TLS inspection. Use the `pnpm` scripts (they set `--use-system-ca`). |
| edge-tts fails or returns no timings | Upgrade: `pip install -U edge-tts` (needs ≥ 7.3.1). |
| Editor stuck on "Loading…" in dev | Don't write dev-server logs inside the project folder (Fast Refresh loop). |
| Edit or delete returns 409 | The project is rendering; wait for it to finish. |
| Scene didn't change after editing | Only edited scenes are stale. Change the seed (🎲) to force a new image. |
| `.env.local not found. Continuing without it.` | Harmless notice from Node. |
